支持与反馈

请通过 GitHub Issues 联系我们。发帖需要 GitHub 账号，内容公开。请提供应用版本、iOS 版本和不含敏感信息的复现步骤。

请勿上传真实记录、密码、密钥、备份或恢复材料。应用打不开时，请勿先卸载，以免丢失唯一的本地副本。

常见问题

恢复购买：在设置的会员页面点击“恢复购买”，使用购买时的 Apple 账户。

备份密码：导出时单独设置，导入需要对应密码，导入只新增、不覆盖现有记录。我们无法代为解密。

同步：不能代替独立备份，修改和删除也可能传播到其他设备。

Support

Contact Anxin Studio via GitHub Issues. Posting requires a GitHub account and posts are public. Include the app version, iOS version, and sanitized reproduction steps.

Never attach real records, passwords, keys, backups, or recovery materials. Do not uninstall an app holding your only data copy as a first troubleshooting step.

Restore purchases from the membership screen using the Apple account used for purchase. Backup passwords are set separately during export; import requires the matching password and adds records without overwriting existing ones. Sync is not an independent backup.
