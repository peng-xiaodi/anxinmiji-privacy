隐私政策

安心工作室（Anxin Studio） · 生效日期：2026-09-11

本政策适用于安心密记（AnXinMiJi / SecureNotes）。我们以本地保存为基础，不运营收集记录内容的服务器，不在应用中加入广告、跨应用跟踪或第三方行为分析 SDK。

记录与设备存储

记录、图片和分组保存在设备中。当前版本加密记录标题、正文、图片及自定义分组名称；标识符、时间、排序、分组关系及部分设置等元数据并非全部加密。口令提示不是秘密存储，请勿把口令写进提示。搜索在设备中处理。

口令与生物识别

应用使用 Apple Keychain 管理必要的密钥和解锁凭据。启用 Face ID 或 Touch ID 后，系统负责认证；应用不能读取面容或指纹模板。生物识别不是备份，也不会随备份文件恢复。我们无法替你找回口令或解密记录。

可选 iCloud 同步

启用后，相关应用数据通过 Apple 的私有 CloudKit 数据库同步。密钥相关状态可能使用 iCloud Keychain，取决于系统设置和恢复路径。这些是 Apple 服务，不是开发者运营的存储服务。同步仍包含未全部加密的元数据，同步不等于独立备份。关闭同步不会自动删除已有云端副本。

图片、复制与备份

系统图片选择器仅提供你选中的图片。主动复制会把内容放入系统剪贴板。导出需要单独设置备份密码，备份包含记录、图片、分组、回收站及恢复分组访问所需信息，整个文件由备份密码加密。保存位置由你通过系统文件界面选择，相应存储服务可能处理该文件。导入新增记录，不覆盖现有记录；重复导入可能产生重复项。请保管好文件与密码。

购买

免费版最多 10 条有效记录，终身会员为一次性内购，无自动续费。付款由 Apple 处理，我们不接收银行卡号或支付密码。应用通过 StoreKit 在设备上检查交易和会员权益，并支持恢复购买。Apple 按其政策处理商店和交易信息。

保存与删除

数据保留到你主动删除或设备存储被移除。移入回收站不是永久删除；在回收站永久删除后，相应应用记录不再保留。同步开启时，删除可能传播到其他设备。导出文件、系统备份、云端副本和系统保留的 Keychain 项目有各自生命周期；卸载不保证它们一并删除。开发者不持有可供你请求删除的记录副本。

网站与支持

本网站使用 GitHub Pages，不添加广告或分析脚本。GitHub 可能按其政策处理访问日志、IP 地址和你提交的内容。支持使用 GitHub Issues，需要 GitHub 账号且内容公开。请仅提供去除敏感信息的复现步骤，不提交记录正文、密码、密钥、备份或恢复材料。我们仅使用你主动提供的信息处理反馈。

变更与联系

政策变化会更新本页日期，重要的数据处理变化按适用要求提示。联系主体：安心工作室（Anxin Studio），GitHub：peng-xiaodi。本政策不构成独立安全审计或绝对安全保证。

Privacy Policy

Anxin Studio · Effective September 11, 2026

AnXinMiJi / SecureNotes is local-first. We do not operate a server collecting your records. The app contains no advertising, cross-app tracking, or third-party behavioral analytics SDKs.

Device storage

The app stores records, images, and groups on-device. It encrypts record titles, content, images, and custom group names. Identifiers, dates, ordering, group relationships, and some settings are not all encrypted. Password hints are not secret storage: do not put your password in a hint. Search runs on-device.

Passwords and biometrics

Apple Keychain manages necessary keys and unlock credentials. Face ID and Touch ID are optional and handled by the system; the app cannot access biometric templates. Biometrics are not a backup and are not restored from a backup file. We cannot recover your password or decrypt your records for you.

Optional iCloud sync

Enabled sync uses Apple's private CloudKit database. Key-related state may use iCloud Keychain depending on settings and the recovery path. These are Apple services, not developer-operated storage. Synced metadata is not all encrypted. Sync is not an independent backup. Turning it off does not automatically delete existing cloud copies.

Images, clipboard, and backups

The system photo picker shares only selected images. Copying places content on the system clipboard. Export requires a separate backup password. The encrypted file includes records, images, groups, trash, and information needed to restore group access. You choose its destination; the selected storage provider may process the file. Import adds records without overwriting existing ones; repeated imports may create duplicates. Protect both the file and password.

Purchases

The free tier allows up to 10 active records. Lifetime membership is a one-time purchase without automatic renewal. Apple handles payment; we receive no card numbers or payment passwords. StoreKit checks transactions and entitlements on-device and supports restoring purchases. Apple processes store and transaction information under its policies.

Retention and deletion

Records remain until deleted or device storage is removed. Trash is not permanent deletion; permanently deleting an item removes the corresponding app record. With sync enabled, deletions may propagate. Exported files, system backups, cloud copies, and retained Keychain items have separate lifecycles. Uninstalling does not guarantee their removal. We hold no copy of your records to delete on your behalf.

Website and support

GitHub Pages hosts this website without advertising or analytics scripts added by us. GitHub may process access logs, IP addresses, and submitted content under its policies. GitHub Issues requires a GitHub account and posts are public. Share only sanitized reproduction steps, never records, passwords, keys, backups, or recovery materials. We use voluntarily submitted information to address feedback.

Changes and contact

Updates appear here with a revised date; material changes will be communicated as applicable. Contact Anxin Studio via GitHub peng-xiaodi. This policy is not an independent security audit or a guarantee of absolute security.
